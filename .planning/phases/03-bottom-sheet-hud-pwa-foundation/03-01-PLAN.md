Create three files:

**useBottomSheet.ts** -- Pointer-driven drag hook per D-02 (custom CSS transforms + pointer events, zero dependencies):

```typescript
type SnapPoint = 'peek' | 'half' | 'full';

interface UseBottomSheetReturn {
  sheetRef: React.RefObject<HTMLDivElement>;
  handleRef: React.RefObject<HTMLDivElement>;
  currentSnap: SnapPoint;
  isDragging: boolean;
  snapTo: (snap: SnapPoint) => void;
  collapse: () => void;
}
```

Implementation details:
- Three snap positions computed as fractions of `window.innerHeight`: peek = 0.85, half = 0.50, full = 0.10 (per D-01). These represent the sheet's translateY offset from the top.
- Track pointer events on the drag handle element only (not content area, per Research Pitfall 3). Use `onPointerDown` on handleRef.
- On `pointerdown`: record startY and current translateY, call `setPointerCapture(e.pointerId)`.
- On `pointermove`: compute delta = e.clientY - startY, update `sheetRef.current.style.transform = translateY(${newY}px)` directly on the DOM element (no React state per Research anti-pattern). Clamp between full and peek positions. Set `isDragging = true` in a ref.
- On `pointerup`: find nearest snap point by comparing current translateY to the three snap thresholds. Set `currentSnap` state. Remove inline transform and let CSS transition animate to snap position via a CSS class or CSS variable `--sheet-translate-y`. Release pointer capture.
- Expose `snapTo(snap)` function for programmatic control (tab taps, HUD tap). `snapTo('half')` sets `currentSnap = 'half'` which updates the CSS variable.
- Expose `collapse()` which calls `snapTo('peek')` per D-03.
