Component structure (all within a single `.hud-overlay` div, onClick={onTap} per D-09):

1. **Badge line** (`.hud-badge`): Display `Lv{level} {className}` per D-08. Use `vitals.level ?? character.level ?? 1` for level. Title-case the className (capitalize first letter of each word). If character.name is empty (not logged in), show nothing or a minimal placeholder.

2. **Three bar rows** (`.hud-bars`): Each bar is a `.hud-bar` container:
   - `.hud-bar-track` (full width, 6px height, rounded, dark background per existing pattern `rgb(24 22 35 / 28%)`)
   - `.hud-bar-fill` (width as percentage of current/max, colored via type-specific class)
   - `.hud-bar-label` (absolute positioned text showing "245/312" format, 10px font, light semi-transparent text)

   Three bars in order:
   - **HP**: `vitals.hp / vitals.maxHp`, green gradient (`--color-hp-light` to `--color-hp-dark`)
   - **Mana**: `vitals.mana / vitals.maxMana`, blue gradient (`--color-mana-light` to `--color-mana-dark`)
   - **XP**: `vitals.xpIntoLevel / max(1, vitals.xpToNextLevel ?? 1)`, gold gradient (`--color-xp-light` to `--color-xp-dark`). If `xpToNextLevel` is null, show full bar.

   Numeric labels: HP shows "245/312", mana shows "180/200", XP shows "1,234/5,000" (use `toLocaleString()` for comma formatting).

3. The entire HudOverlay has `cursor: pointer` and a subtle hover state to indicate tappability (per D-09).
4. Do NOT render the HUD if `character.name` is falsy (user not logged in).
