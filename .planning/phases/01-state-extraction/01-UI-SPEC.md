# Phase 1 -- UI Design Contract

> Visual and interaction contract for Phase 1: State Extraction. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Phase Nature: Preservation Contract

Phase 1 is a **pure internal refactoring** -- decomposing `App.tsx` from 1,655 lines / 88 `useState` calls into 7 domain-split React Contexts with `useReducer`. There are **zero visual changes, zero layout changes, zero new components, and zero new interaction patterns**. The player sees the exact same UI before and after this phase.

This design contract therefore serves as a **regression baseline**: it documents the existing visual system that must be preserved identically through the refactoring. The executor must not introduce any visual deviation.

**Regression standard:** After state extraction, every pixel, animation, interaction, and timing must be indistinguishable from the pre-refactoring state. The verification method is `./gradlew demo` with manual visual comparison.

## Regression Verification Checklist

Since this phase is a preservation contract, the design contract defines what the executor must verify has NOT changed:

### Visual Regression Points

| Area | What to Verify | Method |
|------|---------------|--------|
| Login screen | Login overlay renders with gradient banner, form validation works | `./gradlew demo` -- visual + functional |
| Topbar | Gradient background, pulse animation on important elements | Visual inspection |
| Sidebar panels | All 14+ panels render with hover lift, glow effects, glass-morphism | Click through each panel |
| Progress bars | HP (green), Mana (blue), XP (gold) bars with correct gradients and glow | View character panel |
| Canvas | PixiJS world scene renders, entities display, parallax works, 60fps maintained | Navigate rooms, observe FPS |
| Combat | Combat target display, action bar, floating text, status effects | Initiate combat |
| Chat | Messages display correctly in chat panel | Send/receive messages |
| Ambient effects | Background orbs drift, ambient animations play | Observe idle state |
| Responsive | Layout adapts at breakpoints (480px, 960px) | Resize browser window |
| Reduced motion | Animations disabled when `prefers-reduced-motion: reduce` is set | OS accessibility toggle |

### Functional Regression Points

| Area | What to Verify |
|------|---------------|
| State hydration | All GMCP packages populate UI correctly (vitals, room, inventory, quests, etc.) |
| Canvas bridge | `gameStateRef` updates synchronously during render -- no 1-frame stale data |
| Disconnect/reconnect | All 7 contexts reset cleanly on disconnect; no stale state on reconnect |
| Panel data | Every panel shows correct data after room changes, combat, inventory changes |
| WebSocket | Connection, disconnection, and GMCP message handling unchanged |
| Keyboard shortcuts | All existing keyboard shortcuts continue to work |
| Audio | Audio controls and sound effects unchanged |
