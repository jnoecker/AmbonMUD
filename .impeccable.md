## Design Context

### Users

**Primary audiences (in priority order):**

1. **The creator's niblings** — young players with their own zones in the MUD. The UI must be welcoming, readable, and fun for younger users who may not be heavy gamers. Encouraging reading and exploration is a design goal.
2. **Portfolio visitors** — recruiters, hiring managers, and engineers evaluating this as a technical showcase. The UI should demonstrate craft, polish, and attention to detail.
3. **MUD enthusiasts** — players familiar with text-based games who appreciate the genre but welcome a modern graphical layer on top of classic MUD mechanics.

**Context of use:** Players connect via browser (canvas client) or telnet. Sessions range from quick check-ins to longer exploration. The game is text-first — the graphical client enriches but never replaces the text experience.

### Brand Personality

**Three words:** Surreal. Magical. Adventure.

**Voice & tone:** Warm and inviting, never intimidating. A sense of wonder and gentle mystery — like stepping into a storybook world. Playful without being childish. The UI should feel like a cozy magical space, not a hardcore dungeon crawl.

**Emotional goals:** Evoke the feeling of Stardew Valley or Disney Dreamlight Valley — cozy comfort with an ever-present magical undertone. Players should feel safe to explore, curious about what's around the next corner, and delighted by small details.

### Aesthetic Direction

**Visual tone:** Cozy fantasy with glass-morphism depth. Soft, jewel-toned colors on dark translucent surfaces. Warm lighting metaphors (glows, sparkles) rather than harsh contrasts.

**Current palette:** Purple/blue dominant with gold accents — open to evolution. The jewel-tone foundation (lavender, pale blue, dusty rose, moss green, soft gold) is strong and should be preserved as a base, but can grow.

**Typography:**
- Display: Cormorant Garamond (serif) — elegant, storybook feel
- Body: Nunito Sans (sans-serif) — friendly, highly readable
- Mono: JetBrains Mono — clean technical text

**Theme:** Dark-first today, but light mode is planned. Design tokens (CSS custom properties) should support both themes. When building light mode, preserve the magical warmth — don't just invert colors.

**References:** Stardew Valley (cozy, inviting, gentle color palette), Disney Dreamlight Valley (magical atmosphere, approachable adventure).

**Anti-references:** Hardcore dark MMO UIs (sharp edges, aggressive reds, skull iconography). Generic Bootstrap/Material admin dashboards. Anything that feels cold, clinical, or intimidating.

### Design Principles

1. **Cozy first, cool second.** Every design choice should make the space feel warm and inviting. Rounded corners, soft shadows, gentle gradients. If a choice feels harsh or intimidating, soften it.

2. **Magic in the details.** Small touches — a sparkle on hover, a gentle pulse on an important element, a smooth transition — create the feeling of a living magical world. Prefer subtle, ambient animation over flashy effects.

3. **Readable above all.** This is a text-heavy game played by younger users and portfolio reviewers alike. Typography, contrast, and spacing must prioritize readability. WCAG AA contrast minimum for all text; AAA where practical.

4. **Layered depth, not clutter.** The glass-morphism aesthetic works because it creates visual hierarchy through translucency and blur. Panels should breathe — generous padding, clear separation, no cramming. Let the magical background peek through.

5. **Accessible by nature.** The game is text-first and inherently accessible via telnet. The rich client should match that standard: support reduced motion (`prefers-reduced-motion`), maintain color-blind-safe palettes, ensure keyboard navigation works everywhere, and target WCAG AA compliance across the board.

### Technical Design System

**Styling approach:** Pure CSS with custom properties (design tokens) in `:root`. No CSS framework or preprocessor. All theming via variables — no hardcoded color values in component styles.

**Spacing scale:** 4px base (`--space-1` through `--space-6`: 4, 8, 12, 16, 24, 32px).

**Border radius:** `--radius-sm` (6px), `--radius-md` (10px), `--radius-lg` (16px), `--radius-xl` (24px).

**Elevation:** Three shadow levels (sm, md, lg) plus a glow variant. Translucent panels use `backdrop-filter: blur()`.

**Motion:** Soft custom easings (`--ease-in-soft`, `--ease-out-soft`, `--ease-in-out-smooth`). Ambient animations (drift, pulse) run 2-11s. UI transitions are 200-300ms. Always respect `prefers-reduced-motion`.

**Interaction patterns:**
- Hover: lift 1px (`translateY(-1px)`)
- Active: scale down 2-4% (`scale(0.96-0.98)`)
- Focus: blue/purple ring (2px + 4px spread)
- Disabled: opacity 0.38-0.62, no pointer events

**Responsive breakpoints:** Desktop (960px+), tablet/mobile (< 960px), small phone (< 480px). Mobile uses `100dvh` and safe-area insets.

**Canvas rendering:** PixiJS for game world, particles, and combat. React for UI panels, forms, and overlays. Terminal (xterm.js) as popout on input focus.
